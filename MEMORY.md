## Key technical facts established so far

1. **The problem is not "you cannot differentiate a cliff."** The spike function `Theta(u - thr)` has derivative 0 almost everywhere and is undefined at one point. The real issue is that the naive chain-rule gradient is either 0 (silent neurons, vanishing signal) or infinite (Dirac at firing). The spike *timing* is a smooth function of weights (IFT); only spike *existence* (birth/death) is genuinely non-differentiable.

2. **Exact math exists for fired neurons.** `dt/dW = -Kv / (du/dt)` via the implicit function theorem (SpikeProp lineage, Bohte 2002; TTFS, Mostafa 2018). Verified in literature to high precision.

3. **The reset jump IS solvable** — via saltation matrices (Aizerman–Gantmakher). For the scalar membrane with hard/additive reset, `Sigma = du/dt^+ / du/dt^-`, and the adjoint jump is `lambda^- = Sigma^T lambda^+`. The cliff is NOT "mathematically impossible"; only spike birth/death has no classical derivative. (N/A under D1 — single-spike TTFS has no reset jump.)

4. **Spike birth/death is solvable with probability theory**, not calculus:
   - Escape-noise / stochastic neuron equivalence: surrogate gradient = exact gradient of the expected spike rate in the noise limit (Gygax & Zenke 2025).
   - REINFORCE-style estimators with spike-timing baselines are an alternative.

5. **The accuracy gap is a training gap more than an architecture gap** (Wagenbach 2026 analysis). SNN ImageNet went 67-70% (2020) → 85.06% (MSViT, 2025) vs ~90%+ ANNs. CIFAR-10 gap now ~1.5 pts. Surrogate-gradient training is ~8 years old vs 30 for ANNs.

6. **The spike-time map is NOT everywhere smooth — FD-based verification has a kink.** The clamped kernel onset `K(d<=0)=0` makes `t_f(W)` non-differentiable at `t_f = t_in` (an input-arrival instant) and at bias-only crossings. Two-sided central differences are invalid there; the analytic IFT gradient is exact. Any finite-difference gradient check must use well-conditioned forward passes where every neuron fires strictly after all its inputs (min margin ≥ 0.13). Verified in E5d (FD error 1.5e-10 at safe gap → 0.38 at the kink) and was the root cause of the earlier "bias gradient bug" scare. Same non-differentiability family as spike birth/death → SP-02's statistical credit.

7. **Kernel normalization is subtle but settled.** `k_peak = max_d K_unscaled(d)` includes the `(tm-ts)` divisor; `tau_m=15, tau_s=4 → k_peak≈0.0412388`, peak value of K exactly 1. Bias must differ from `theta=1.0` (bias_val=1.0 = theta makes the bias alone graze the threshold at the kernel peak → fired/silent flips between engines).

8. **The existence channel's far-dead gradient is bounded below — but ONLY with the correct peak-extremum definition.** The MLE objective `-log p` (`p = sigmoid((u_peak - theta)/T)`) gives `dL/du_peak = -(1-p)/T → -1/T` as `p → 0`, fixing the naive `sigma'` draft (which vanishes). BUT the naive argmax over `[0, t_max]` collapses onto the pre-input plateau (`u=0`) for any subthreshold neuron → `K(t_peak - t_in) = 0` → zero gradient. The peak must be searched over the **response window** (t ≥ earliest contributing event) and, for all-negative responses, the interior **minimum** extremum is used (still `u'=0`, envelope holds). With this fix: E6 gradients 0.88→1.00 for `m0 ∈ {2,3,5,8}`, revived spike times exact to 3.6e-15, envelope `d(u_peak)/dW = K` verified ~1e-9 (E8c).

9. **`lam` (channel weight vs timing CE) is the revival throttle, with measured sensitivity.** At `lam=1` the channel competes with the timing loss's push-DOWN on wrong-class outputs and revival is slow (E7 plateaus ~0.63). `lam=5` revives correct-class silent outputs and learns (0.99). The far-dead toy works at `lam=1`; the output-layer task needs more. Reported, not hidden.

10. **The engine is already a three-factor rule; only the hidden-layer learning signal is non-local.** The per-layer gradient is `dW_ji = L_j · e_ji` with local eligibility `e_ji = K(t_{l+1,j} − t_i)` (the IFT derivative) and learning signal `L_j = −lam_j/u'_j`; temporal locality is already exact + O(1) (retained state per layer = `(t_prev, t_post, u')`, the grid scan is a transient recomputation). The ONLY non-local term is the hidden-layer signal `lam_i = Σ_j w_ji (lam_j/u'_j) K'(t_{l+1,j} − t_i)` (the `W^T` transport). This is what SP-04 removed. (SP-04 research doc §2–4.)

11. **Per-layer local loss (D3) is an EXACT local mechanism, verified.** Each hidden layer gets its own trainable readout (`latency CE on R_l @ t_eff`) + its own existence channel; the output layer its own CE. Because each local loss is a real scalar objective, the returned gradient is its exact derivative — E1 gradcheck passes at depth 3/4 and with mixed fired/silent (dot ≤ 2.2e-6, w ≤ 2.4e-6, 0 status flips). Memory O(1) measured (24.65 B/neuron flat across G=401→16001). No accuracy regression vs SP-02 (deep 0.927 vs ref 0.969 on 2-hidden; 4-hidden net trains to 0.969, depth utility +36.5 pp). Q4.1 measured: ref 0.990 / deep 0.969 / fa 0.812 / contrastive 0.948 — FA (random fixed feedback) is worst despite highest per-layer cosine; fully-forward-only contrastive is ~4 pp under ref; no hard barrier found. (SP-04 results doc.)

12. **`latency_cross_entropy`'s gradient is deliberately the unclamped softmax gradient.** The loss clamps `p_y` at 1e-12 (placeholder for silent outputs), but the returned `dL = beta/B*(onehot − p)` ignores the clamp — intentional: it keeps pushing silent label-targets to fire (SP-02 E9). Consequence: FD-vs-analytic checks are only valid when the label's probability is real, i.e., labels must never point at an always-silent output neuron in a gradcheck (SP-04 E1 mixed nets silence hidden layers only).

13. **The latency-CE temperature `beta` controls whether exact timing gradients can express a useful signal.** At beta=1 the softmax over spike times is nearly uniform, so both engine and baseline congest near chance on real data (ANN oracle 0.32). Raising beta=3.0 sharpens the softmax and amplifies the IFT timing gradient: engine overfit 0.35→0.56, while the surrogate *drops* (0.36→0.22) — beta is the knob that lets the exact engine separate from the surrogate. Kept identical (beta=3.0) in all benchmark modes for apples-to-apples.

At the default 15k samples the engine's generalization closed the gap and it pulled ahead (0.273 vs 0.238). ## Review of the "other AI" engine code (2026-08-13)

Verdict: well-organized **skeleton, not a runnable engine**. Not verification.

Problems found (priority order):
1. **Core kernels are placeholders**: `forward_layer` ("Grid-bracket + Newton Exact Root Find Logic goes here..."), `FastMSNN.forward/backward` ("Omitted full loop for brevity"), `forward_conv_layer` referenced but never defined. No loss head / output layer handling.
2. **Revival does not solve the death attractor**: `ds = s(1-s)/T` ~ 0 far below threshold; annealing shrinks T, so the rescue signal weakens over training and only reaches near-threshold neurons. Far-dead neurons stay dead.
3. **Saltation not wired in** and possibly unnecessary in max-1-spike TTFS (neuron dead after first spike).
4. **Bias gradient bug (suspected)**: `backward_layer` uses the impulse kernel `Kv` for the bias; a constant bias current needs the step response, not `Kv`. Must be fixed and covered by gradient check.
5. **"Exact / 0.00% / 9.9e-12 verified" framing overreaches**: exactness only covers fired neurons; toy verification != solving the problem.

What was sound in it:
- IFT-based `dt/dW` math (`alpha = la/upu`, `grad += -alpha*Kv`) is correct.
- `lam_prev[e] += alpha * W[nf,c] * Kdv` is correct adjoint propagation for fired neurons.
- Isolating the revival channel from exact gradients is good engineering.
- `apply_saltation_adjoint` is a correct scalar saltation update in adjoint form.
